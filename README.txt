PORTFOLIO WILDAN — SIGNATURE EDITION

Isi folder:
- index.html
- style.css
- images/foto-wildan.jpg

Karakter desain:
- Dark futuristic / editorial portfolio
- Pure HTML5 + CSS3 (tanpa Bootstrap/Tailwind)
- HTML semantik
- CSS Grid + Flexbox
- Responsive desktop/tablet/mobile
- CSS animation & micro-interaction
- Accessibility dasar + prefers-reduced-motion

Cara buka lokal:
1. Buka folder di VS Code.
2. Klik kanan index.html -> Open with Live Server.

Cara update deployment Vercel yang sudah ada:
1. Ganti file index.html dan style.css pada folder project lokal dengan versi ini.
2. Pastikan folder images/foto-wildan.jpg ikut ada.
3. Di terminal project jalankan: npx vercel --prod
